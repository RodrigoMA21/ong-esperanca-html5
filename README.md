# ONG Esperança — Projeto HTML5

Projeto acadêmico desenvolvido com HTML5 semântico, com foco em
acessibilidade, organização estrutural e validação de formulários.

## Páginas

- `index.html` — apresentação institucional e informações de contato.
- `projetos.html` — projetos sociais, doações e voluntariado.
- `cadastro.html` — formulário de cadastro com validações nativas HTML5.

## Tecnologias
- `HTML5`
- `HTML5 Semântico`
- `Formulários e validações nativas`
- `Acessibilidade`
- `W3C Validator`
